# SORT GESTURE INOFRMAL STUDY

Thanks for taking a few minutes to help us out.

#### 1. Phase
Imagine you are placing objects into different zones on this table. The robot recognizes what you do and wants to tell you—using only its movement (no screens, no sound)—whether the object was placed correctly, incorrectly, or if it is uncertain.

There are no right or wrong answers here. We just want to find out what kind of movements feel most intuitive to you.

#### 2. Phase
- You place an object correctly in its designated zone. How should the robot arm move to quickly and clearly tell you: 'Great job, keep going!'?

- You place an object in the wrong zone. How should the robot arm move to tell you: 'Stop, that was incorrect!'?

- You place an object that the robot cannot identify or is uncertain about (e.g., partially hidden or unknown object). How should the arm express: 'I am not sure / I don't know this object'?
